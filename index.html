TV Verdes Mares · Configuração Inicial

Para sincronizar dados entre todos os dispositivos, conecte ao banco Supabase. Feito uma vez, nunca mais precisa repetir.

1
Acesse supabase.com → faça login → clique em New Project e aguarde ~2 min o projeto inicializar.
2
No menu lateral, vá em SQL Editor → cole e execute o conteúdo do arquivo setup.sql para criar as tabelas.
3
Vá em Settings → API → copie a Project URL (termina em .supabase.co) e a anon/public key.
